# Zenvora Media Bot

بوت تيليجرام خاص لتنزيل الوسائط من الروابط العامة المدعومة.

## المتطلبات
- Python 3.10 أو أحدث
- TELEGRAM_BOT_TOKEN
- OWNER_ID
- FFmpeg لاستخراج MP3

## التشغيل المحلي
pip install -r requirements.txt
python bot.py

لا تضع رمز البوت في ملفات GitHub. أضفه كمتغير بيئة في الاستضافة.
احترم حقوق النشر وشروط المنصات التي تستخدمها.
